# Card Tradz — graded card trading marketplace (clickable demo)

**Demo only — no real trades, payments, accounts or cert lookups.** All listings, users and comps are fictional sample data.

Static SPA (vanilla JS, no build step, no third-party libraries). State persists in `localStorage`.
- `index.html`, `styles.css`, `app.js` — app
- `data/listings.json` — 60 sample listings, 12 fictional users, sample comps (shaped like eBay sold / Alt sales), demo portfolio
- `gen_data.py` — regenerates sample data
- `sortable.js` — shared sortable-table helper
